# 11-实施任务分解与里程碑

## 1. 任务拆分总览

### 阶段 A：核心契约落地（P0）
1. AIAgent 新增 `hermes_home` 参数并建立 `self._hermes_home`。
2. run_agent 到 model_tools 到 registry 的 `hermes_home` 透传链打通。
3. MemoryStore 实例目录化改造。

### 阶段 B：skills 数据面隔离（P0/P1）
1. skill_utils 关键函数增加 home 透传。
2. skills_tool / skill_manager_tool 去静态目录依赖。
3. skill_commands 与 skills prompt 构建支持实例目录。

### 阶段 C：缓存与衍生代理一致性（P1）
1. skills prompt cache key 纳入 home。
2. snapshot 路径实例化。
3. background review / delegate 子代理透传 home。

### 阶段 D：协作组策略落地（P1）
1. CollabGroup 策略枚举冻结：`sequential|parallel|coordinator`。
2. 默认策略设置为 `sequential`。
3. 协调器执行与降级回退链路实现。
4. 审计日志增加策略与降级事件记录。

### 阶段 E：Orbit 接入与验收（P1）
1. Orbit 统一封装 `hermes_home_for(...)` 与 `execute_group_run(...)`。
2. 双助理并发、组策略和回归测试执行。
3. 灰度上线与回滚预案演练。

## 3. 里程碑定义

### M1：可编译可运行
- 所有签名改造完成，基础单测通过。

### M2：隔离生效
- 双实例并发测试通过，memory/skills 不串写。

### M3：衍生链路闭环
- review 与 delegate 一致性测试通过。

### M4：协作组策略闭环
- sequential/parallel/coordinator 三策略联调通过。
- coordinator 失败降级验证通过。

### M5：Orbit 联调通过
- Orbit 端按 assistant 目录接入成功，回归通过。

## 4. Done Definition
满足以下条件视为完成：
1. 本目录设计契约均被实现。
2. 六类关键场景测试全部通过。
3. 默认兼容路径无行为回归。
4. 可提供“组策略执行 + 降级回退 + 成员隔离”的端到端演示记录。
